# QuantLab

A configurable backtesting and strategy research platform for evaluating trading strategies against historical market data.

## Features

- [ ] Historical price data fetching with local caching
- [ ] Pluggable strategy interface
- [ ] Event-driven backtest engine with transaction costs
- [ ] Performance metrics (Sharpe, max drawdown, CAGR, win rate)
- [ ] Walk-forward validation
- [ ] YAML-configured experiment runs
- [ ] Strategy comparison reports and equity curve charts
